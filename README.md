# SIPMEDIA — Frontend

Peminjaman Ruang Media & Peralatan Sekolah. Situs statis untuk GitHub Pages; data dan logika ada di Google Apps Script.

- Isi `js/config.js` → `GAS_URL` dengan URL `/exec` backend sebelum diunggah.
- Langkah lengkap: lihat `PANDUAN-DEPLOY.md`.
- Pustaka bawaan di `vendor/` (lihat `vendor/README.md` untuk lisensi).
